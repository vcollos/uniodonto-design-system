# Submarcas

Vitrine das assinaturas das Soluções Uniodonto (`assets/Submarcas`): Banco U, Dental U, Mobile, RXScan, Sig U, UCX, U Fast, U Hub e U Rede, cada uma em positivo e negativo.

## Regras

- Use sempre o arquivo oficial (`<submarca>_positivo.svg` / `_negativo.svg`); nunca redesenhe nem recolora.
- Positivo em fundo claro (`n-0`, `bg`); negativo sobre `uni-vinho-escuro`.
- As submarcas seguem a arquitetura monolítica: mesmas regras de área de proteção, tipografia e paleta da marca-mãe, e assinatura com o selo SomosCoop.
- Os positivos de Sig U (ciano), U Fast e U Hub (goiaba) e U Rede (roxo) são só na cor vibrante: em fundo branco o contraste é baixo — prefira fundo vinho ou a versão negativa em peças pequenas.
