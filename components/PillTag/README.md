# PillTag

Etiqueta em pílula do brand book: contorno vinho de 1px, cantos totalmente arredondados, texto vinho em bold itálico.

## Uso

- `pill-tag` para rotular seções, categorias e exemplos ("Cor oficial marca", "Proporção").
- `pill-tag solid` (vinho sólido, texto branco) para nomes de cor e destaques institucionais.
- Texto curto, em caixa alta e baixa. Para status use `badge`.
