# Logos

Arquivos oficiais da marca Uniodonto (pasta de assets da marca no Drive). Todos os SVG trazem a cor embutida e funcionam direto num `<img>`.

- **Horizontal (logotipo + símbolo à direita):** `logo-horizontal-vinho.svg` (institucional, preferencial) e as versões não institucionais com símbolo `roxo`, `ciano`, `goiaba`, `pessego`. Sobre vinho: `logo-horizontal-negativo-branco.svg` (institucional) e `-negativo-roxo`, `-ciano`, `-goiaba`, `-pessego` (logotipo branco, símbolo colorido). `-branco-alt` é uma segunda exportação da versão branca.
- **Vertical (símbolo centralizado acima):** `logo-vertical-vinho.svg`, `-roxo`, `-ciano`, `-goiaba`, `-pessego`; sobre vinho `logo-vertical-negativo-branco.svg` e `-roxo`, `-ciano`, `-goiaba`, `-pessego`, `-lima`.
- **Só o logotipo (sem símbolo):** `logotipo-vinho.svg` e `logotipo-branco.svg` — use para a composição distanciada e para medir o selo SomosCoop (máx. 3/4 desta largura).
- `logo-eventos-positivo.svg` / `logo-eventos-negativo.svg`: versão para eventos e patrocínios (o negativo tem fundo vinho próprio). PNG para e-mail: `logo_vinho_email.png`.
- Símbolo colorido só em peças não institucionais; avatar sempre vinho. Área de proteção = altura do "U"; nunca distorça, rotacione ou aplique efeitos.
