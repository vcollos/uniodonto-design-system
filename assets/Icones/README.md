## Regras

- Bicolores: acento numa cor vibrante (`uni-goiaba`, `uni-ciano`, `uni-pessego`) com traço vinho. Use em `<img>`, mínimo 40px, **sempre acompanhados do descritivo** (`AcessoRapido`).
- Os arquivos trazem alguns tons exportados levemente diferentes dos tokens (ex.: #a30069, #820d57, #69c9df); são os originais — não recolora.
- A família completa (destaque, serviços, documentos) está no arquivo-fonte `Uniodonto_icones.ai` da pasta de ícones da marca.
