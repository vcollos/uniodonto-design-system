# Singulares

Template oficial da assinatura das Singulares. Símbolo e logotipo em curvas; **o nome da Singular é texto editável** (`<text>` em Georama Itálico), com "Rio Grande do Norte" como exemplo. Use o componente `AssinaturaSingular` para digitar o nome e baixar o SVG pronto.

| Arquivo | Composição |
| --- | --- |
| `horizontal-distante-A-*` / `-B-*` | Logotipo + nome, símbolo afastado (preferencial) |
| `horizontal-proxima-A-*` / `-B-*` | Logotipo + símbolo + nome juntos |
| `vertical-distante-*` / `vertical-proxima-*` | Composições verticais |
| `horizontal-proxima-B-branca-extra` | Composição toda em branco |

`-positiva` (logotipo #810e56 `uni-vinho-escuro`, símbolo e nome #bf9cff) para fundo claro; `-negativa` (logotipo branco, símbolo e nome #bf9cff) para fundo vinho.

- A fonte não está embutida: quem abrir o SVG precisa de Georama Itálico instalada; para gráfica, converta o nome em curvas.
- Ao trocar o nome, recalcule o `viewBox` (o nome muda de largura). Entreletra 25, caixa alta e baixa.
