# Símbolo

Símbolo de comando "U" (arquivos oficiais, cor embutida). `simbolo-vinho.svg` é o institucional (avatar, verso de papelaria); `simbolo-roxo` é o das Singulares; `-ciano`, `-goiaba`, `-pessego` são não institucionais. Sobre vinho: `simbolo-negativo-branco.svg` (institucional) e `-roxo`, `-ciano`, `-goiaba`, `-pessego`, `-lima`.

Nunca aplique um símbolo de cor vibrante sobre fundo de outra cor vibrante — sobre cor, use o vinho.
